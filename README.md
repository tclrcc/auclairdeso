# Au clair de So

Site vitrine et prise de rendez-vous en ligne pour une praticienne médium.

## Stack

- Backend : Java 25, Spring Boot 4.1, Spring Modulith, Spring Security, PostgreSQL 17
- Frontend : Angular 22 (SSR et prérendu)
- Infra : Docker Compose, nginx, GitHub Actions, VPS OVH

## Structure

| Dossier     | Contenu                              |
|-------------|--------------------------------------|
| `backend/`  | API Spring Boot (Maven)              |
| `frontend/` | Application Angular                  |
| `infra/`    | Docker Compose, configuration nginx, scripts |
